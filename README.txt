German 1000 — personal German vocabulary PWA

This is a mobile-first Progressive Web App. It stores learning progress in the browser on the device.

FASTEST WAY TO PUT IT ONLINE
1. Unzip this project.
2. Open https://app.netlify.com/drop
3. Drag the unzipped project folder onto the Drop area.
4. Netlify will give you a live HTTPS URL ending in netlify.app.
5. Open that URL on your phone and choose Add to Home Screen / Install App in the browser menu.

To publish an updated version later, drag the updated project folder to the site's Deploys page.

IMPORTANT
- Progress is stored locally in the browser/device using localStorage.
- Clearing browser/site data can erase progress.
- This is currently a personal vocabulary trainer without cloud sync/accounts.
